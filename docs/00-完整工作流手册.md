# 我的 ComfyUI 生图与视频生成工作流

> 更新：2026-08-28
> 适用范围：角色、场景、道具、四视图、关键帧、图像编辑和 MiniMax H3 视频生成
> 文件依据：本目录当前实际存在的 ComfyUI JSON

## 一、使用前确认

以后提出生图、图片编辑、四视图、关键帧或视频生成任务时，如果没有明确指定工具，Codex 必须先询问：

```text
这次是否使用你保存在“AI短视频/06-AI温情故事剧场/comfyui工作流/”中的 ComfyUI 工作流？
```

- 回答“是”后，按本文件选择具体 JSON、分组、输入顺序和参数。
- 回答“否”后，再使用用户指定的其他工具或方案。
- 用户已经明确说“使用 ComfyUI”或明确指定其他工具时，不重复询问。
- 确认使用 ComfyUI 不等于授权安装模型、下载节点、产生付费调用或自动发布成片；这些操作仍需单独确认。

## 二、完整生产链

```text
剧本与台词确认
→ 角色、场景和道具单图
→ 已确认角色制作四视图（只在需要时）
→ 人物/道具与场景合成关键帧
→ 关键帧人工验收
→ MiniMax H3 图生视频并生成音频
→ 剪辑、字幕、统一配乐和质检
```

不要在角色图尚未确认时制作四视图，也不要在静态关键帧尚未通过时批量生成视频。

## 三、生图工作流路由

### 1. 从零生成角色、场景或道具

使用：

```text
▶▷Krea2-风格扩展流（3946种）.json
```

适用：角色定妆图、独立场景底图、独立道具参考图，以及不依赖参考图的单张画面。

当前实测稳定设置：

```text
风格提示词选择器：开启
风格分类：krea2_397styles-photography_摄影
具体风格：Photography（已验证）
UNET：Krea2\krea2_turbo_int8_convrot.safetensors
VAE：qwen_image_vae.safetensors
比例：9:16
步数：8
CFG：1
采样器：euler
调度器：simple
降噪：1
```

重要：当前 JSON 内保存的是 `krea2_397styles-3d_render_3D渲染 + Backlit Portraiture`，不是本项目验证过的组合。每次加载后必须手动改成 `krea2_397styles-photography_摄影 + Photography`。

开启风格模板后，主体提示词只写人物或物体、年龄与必要外观、服装、动作、场景和构图。不要重复加入“写实摄影、电影感、曝光、景深、色调、皮肤纹理”等风格词，避免与风格模板冲突。

### 2. 单张图片风格转换

使用：

```text
▶▷krea2-风格扩展流（图生图版）.json
```

适用：保持原图主体，主要改变视觉风格。该工作流不是人物放入场景的默认选择。

当前参数：

```text
UNET：Krea2\krea2_turbo_int8_convrot.safetensors
LoRA：Krea2-功能\Krea2-编辑identity_edit_v1_2.safetensors
LoRA强度：1
步数：10
CFG：1
采样器：euler
调度器：simple
降噪：1
```

### 3. 人物、道具和场景合成或局部修改

使用：

```text
▶▷krea2-图像编辑-整合流.json
```

根据任务只启用一个分组：

```text
▶krea2-双图编辑
▶krea2-单图编辑
▶krea2-图像扩展
▶krea2-局部重绘/移除
```

人物或道具放入场景时使用双图编辑：

```text
加载图像-1：最终场景和构图基础
加载图像-2：需要放入场景的人物或道具
提示词：明确“以图1为场景基础，把图2主体放入图1”，并说明必须保留和不得带入的内容
```

双图编辑没有 `easy stylesSelector`，不选择 `Photography`，也不套用文生图阶段的风格模板规则。

当前主要参数：

```text
UNET：Krea2\krea2_turbo_int8_convrot.safetensors
LoRA：Krea2-功能\Krea2-编辑identity_edit_v1_2.safetensors
LoRA强度：1
步数：10
CFG：1
采样器：euler
调度器：simple
降噪：1
```

每次只生成一张。人物、手部、道具数量或构图基本正确后，最多再比较一至两个种子，不连续批量抽卡。

### 4. 已确认角色生成四视图

使用：

```text
▶▷MiniMaxH3辅助四视图生成流-k2.json
```

适用：人物角色表。书桌、手机、碗、台灯等普通场景或道具不需要四视图。

输入：已经确认的单张角色定妆图。

当前参数：

```text
输入缩放：1024 × 1536
UNET：Krea2\krea2_turbo_fp8_scaled.safetensors
LoRA：Krea2-功能\Krea2-四视图QuadView_krea2_v1.safetensors
LoRA强度：1
VAE：qwen_image_vae.safetensors
步数：10
CFG：1
采样器：euler
调度器：simple
降噪：1
```

四视图提示词只描述角色表目标，不加入摄影风格模板：

```text
Convert the character in the image to a character sheet showing a face close-up, front full body, side full body, and back full body views.
```

## 四、视频生成工作流路由

### 1. 当前默认：稳定低显存图生视频

使用：

```text
MiniMaxH3-图生视频-低显存稳定优化版.json
```

适用：把已经确认的单张关键帧动态化，并同步生成环境声或对白。

输入：每个镜头文档中明确列出的关键帧首图。

当前稳定设置：

```text
分组：MiniMaxH3-图生视频
模式：I2VA
UNET：Minimax_H3\minimax_h3_fl2va_pruned_int8_convrot.safetensors
视频VAE：minimax_h3_video_vae_fp16.safetensors
音频VAE：minimax_h3_audio_vae_fp32.safetensors
LoRA：minimax_h3\minimax_h3_fl2v_lightx2v_turbo_4step_v0.1_comfy.safetensors
LoRA强度：0.75
采样器：res_multistep
调度器：simple
步数：4
CFG：1
首轮比例：9:16
首轮倍率：0.7
帧率：24 fps
MiniMaxH3MemoryEfficientSageAttentionPatch：启用
MiniMaxChunkFeedForward：启用，4 / 4096
MiniMaxLowVRAMAttention：启用，10
TESpeedMiniMaxH3：旁路
RTXVideoSuperResolution：旁路
```

首轮不启用超分。先检查人物、手部、道具、动作、声音和口型；镜头通过后，再单独决定是否提高倍率或做后期放大。

提示词一次只采用一种路线：

```text
路线A：直接使用已经验证的 H3 最终提示词
路线B：简单中文镜头意图 → 工作流提示词增强器 → 使用增强结果
```

不要把简单提示词、增强结果和另一份长提示词叠加。比较两种提示词路线时，保持首帧、时长、种子和采样参数不变。

### 2. 首尾帧、多参考或文生视频

使用：

```text
▶▷MiniMaxH3-加速视频流整合.json
```

按实际任务选择分组：

```text
MiniMaxH3-图生视频
MiniMaxH3-文生视频
MiniMaxH3-首尾帧
MiniMaxH3-多参视频
提示词增强-1（备用）
```

只有任务确实需要首尾帧、多张参考图、参考视频或参考音频时才使用对应分组。每项参考素材必须写明唯一职责和不得转移的属性。

### 3. 暂不作为默认路线

```text
加速ing（不保证都可以使用）.json
```

该实验版曾生成彩纹，且使用的采样器、Turbo LoRA、视频 VAE 和 TESpeed 设置与稳定版不同。除非专门进行对照测试，否则不使用。

## 五、每次任务的交付格式

确认使用本套 ComfyUI 工作流后，Codex 必须在任务文档或回复中写明：

```text
任务类型：生图 / 图片编辑 / 四视图 / 图生视频 / 首尾帧 / 多参考视频
工作流文件：具体 JSON 中文文件名
启用分组：具体分组名称
输入素材：图像-1、图像-2或首帧分别加载什么
风格选择器：开启/关闭；分类；具体风格
模型与采样：UNET、LoRA、步数、CFG、采样器、调度器、倍率
提示词：可直接粘贴的最终内容，或明确说明先经过增强器
时长：视频任务的具体秒数
保存命名：中文文件名前缀
验收重点：本轮只检查哪些问题
```

生图任务必须明确风格选择器状态。双图编辑必须明确图像-1和图像-2。视频任务必须明确首帧文件、时长、保存命名和提示词路线。

## 六、通用验收原则

- 先验证单张或单镜头，再批量生成。
- 一个镜头只有一个主要动作；复杂动作拆镜头。
- 中文界面、字幕和小字优先后期添加，不要求生成模型准确绘制。
- 关键人物脸、服装、手部、道具数量和空间关系优先于最高分辨率。
- 视频出现彩纹、人物漂移、手指错误或口型问题时，先判断是工作流参数、参考图、提示词还是随机种子，不同时修改多个变量。
- 同一问题换两至三个种子仍重复出现时，停止抽卡，修改提示词、拆镜头或更换分组。
