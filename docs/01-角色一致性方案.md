# 角色一致性方案

> 这篇记录为什么「文字描述角色」不管用，以及最终有效的三段式做法。

## 问题

一开始的做法是在每一条视频提示词里写完整的角色描述：

```text
The same minimalist 2D animated stick figure character with a dark navy
bucket hat, cream t-shirt, and plain white face. No pom-pom on the hat.
```

结果：

| 现象 | 实测结果 |
|---|---|
| 帽子上出现毛球 | 9 条片段全部写了 `no pom-pom`，9 条全部画出了毛球 |
| 脸型不一致 | 每条片段的五官比例都不同 |
| 服装颜色漂移 | 深藏青在不同片段里偏蓝、偏黑、偏灰 |

**结论：视频模型对「否定约束」基本无效，对「长描述」只有部分遵循。** 靠文字锁不住角色。

## 为什么关键帧能锁住

图像模型的采样空间比视频模型小得多——它只生成一帧，不需要同时保证时间上的运动连贯。所以：

- 同一提示词 + 同一种子 → 图像模型出图基本可复现
- 同一提示词 + 同一种子 → 视频模型每次都不一样（因为多了时间维度的随机性）

因此**把「角色长什么样」这件事交给图像模型决定，视频模型只负责「怎么动」**。

## 三段式做法

### 第一段：角色立绘

用文生图工作流生成一张角色定妆图，反复抽卡直到满意：

```yaml
工作流:    01-krea2-txt2img-styles.json
风格选择器: krea2_397styles-photography_摄影 + Photography
比例:      9:16
步数:      8 / CFG 1 / euler / simple
提示词:    只写角色本身（年龄、服装、姿态、中性背景）
```

产出一张 `角色立绘-主角.png`。

### 第二段：关键帧锁定

用「双图编辑」把角色放进场景，生成关键帧：

```yaml
工作流:    03-krea2-image-edit.json
启用分组:  ▶krea2-双图编辑（只启用这一个）
图像-1:    场景底图
图像-2:    角色立绘
提示词:    以图1为场景基础，把图2主体放入指定位置；
           保留图1的空间方向与光照；不得带入图2的背景
```

每一帧都从同一张立绘出发，所以**角色的像素特征在每一帧都一致**。

### 第三段：相邻片段共用关键帧

视频生成时，把关键帧当作首尾帧喂进去：

```yaml
工作流:    05-h3-i2v-lowvram.json
Clip 1:    KF01 → KF02
Clip 2:    KF02 → KF03   ← 和 Clip 1 共用 KF02
Clip 3:    KF03 → KF04   ← 和 Clip 2 共用 KF03
```

好处有两层：

1. **锁角色**：每一段的起止状态都是确定的像素，模型没有自由发挥空间
2. **保证衔接**：上一段的结束帧就是下一段的开始帧，剪辑时不会跳

## 四视图什么时候用

只有当同一角色需要**多个视角**（正面 / 侧面 / 背面）时才做四视图：

```yaml
工作流:    04-h3-quadview.json
输入:      已确认的单张角色定妆图
输入缩放:  1024 × 1536
UNET:      krea2_turbo_fp8_scaled.safetensors
LoRA:      QuadView_krea2_v1.safetensors（强度 1）
提示词:    Convert the character in the image to a character sheet
           showing a face close-up, front full body, side full body,
           and back full body views.
```

书桌、手机、碗、台灯这类普通场景或道具**不需要四视图**，单图即可。

## 复用清单

新作品可直接复用：

- 角色立绘（如果沿用同一角色）
- 关键帧生成方法（立绘 + 双图编辑）
- 相邻片段共用首尾帧的剪辑约定
