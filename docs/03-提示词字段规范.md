# 提示词字段规范

> MiniMax H3 的提示词不是「一段话」，是几个固定字段的组合。字段填错比措辞好坏影响更大。

## 四类生成模式

不同模式吃不同的输入，提示词结构也不同：

| 模式 | 输入 | 提示词重点 |
|---|---|---|
| **T2VA** | 无 | 完整描述场景 + 动作 + 声音 |
| **I2VA** | 首帧图 | 只描述「从这一帧开始怎么动」 |
| **FL2VA** | 首帧 + 尾帧 | 描述「怎么从 A 走到 B」 |
| **Ref2VA** | 多张参考图 | 每张参考图写明唯一职责 |

**选错模式是最常见的浪费**：有首帧却用 T2VA，等于让模型重新生成一帧，首帧白给了。

## 字段骨架

### 主体描述

只写必要信息：

```text
一个穿深藏青渔夫帽、米白 T 恤的角色
```

不要写「写实摄影、电影感、景深、皮肤纹理」——这些是风格模板的工作，重复写会冲突。

### 场景与动作

一个镜头只有一个主要动作：

```text
角色从画面左侧走到桌前，停下，低头看向桌上的纸
```

复杂动作拆镜头，不要在一段里塞「走过去 + 坐下 + 拿笔 + 写字」。

### 声音设计（integrated_multimodal_description）

H3 支持同步生成音频，声音要在提示词里明确：

```text
环境声：安静的室内，远处有轻微的风声
动作声：脚步声，纸张翻动声
对白：无
```

**不写声音，模型会自己编**——经常编出与画面不符的环境音。

### 非叙事音乐（non_diegetic_music）

背景配乐单独一个字段：

```text
non_diegetic_music: 低沉的大提琴铺底，节奏缓慢，情绪克制
```

不写这一项时，模型可能生成带鼓点或旋律性过强的音乐，和后期的剪辑节奏打架。

## 四类模式的提示词模板

### T2VA（纯文生视频）

```text
[主体] 一个穿深藏青渔夫帽的角色
[场景] 空荡的房间，只有一张书桌和一盏台灯
[动作] 角色走进画面，在桌前停下，伸手拿起一张纸
[镜头] 中景，固定机位，轻微推近
[声音] 环境声：室内安静，纸张摩擦声
[音乐] 无
```

### I2VA（图生视频，最常用）

```text
[起始状态] 角色站在桌前，手悬在纸面上方（与首帧一致）
[动作] 手落下，指尖触到纸面，随后缓慢向右侧划过
[结束状态] 手停在纸张右侧边缘
[镜头] 保持首帧机位，不移动
[声音] 纸张摩擦声，无对白
```

**关键**：起始状态必须和首帧图一致，否则模型会强行「过渡」到它自己想象的状态。

### FL2VA（首尾帧）

```text
[起始] 与首帧一致：角色坐在床边，低头
[过程] 角色抬头，视线从地面移到窗外
[结束] 与尾帧一致：角色侧脸看向窗外，肩部放松
[镜头] 固定机位
```

尾帧描述要精确，模型才能收敛到目标状态。

### Ref2VA（多参考）

每个参考图必须写明**唯一职责**和**不得转移的属性**：

```text
参考图 1（角色）：提供角色的脸型、帽子和服装
  → 不得转移：背景、光照、姿态
参考图 2（场景）：提供房间布局和光照方向
  → 不得转移：任何人物
参考图 3（道具）：提供桌上物品的形状和材质
  → 不得转移：位置和大小
```

## 提示词路线只能选一条

```text
路线 A：直接使用已经验证过的最终提示词
路线 B：简单中文镜头意图 → 工作流提示词增强器 → 使用增强结果
```

**不要把简单提示词、增强结果和另一份长提示词叠加。** 三个来源的描述会互相冲突，模型只能随机挑一个执行。

比较两种路线时，保持首帧、时长、种子和采样参数不变，只换提示词。

## 自检清单

生成前逐条确认：

- [ ] 模式选对了吗（有首帧就用 I2VA，不要用 T2VA）
- [ ] 一个镜头只有一个主要动作？
- [ ] 起始状态和首帧图一致？
- [ ] 声音字段写了吗（不写模型会编）
- [ ] 非叙事音乐写了吗
- [ ] 有没有用比喻（会被字面渲染）
- [ ] 多角色场景每个角色都写明特征了吗
- [ ] 有没有「隐形施力者」（谁在抬？谁在推？）
- [ ] 镜头物理自检过吗（镜子、倒影、影子方向）
- [ ] 提示词路线只选了一条吗
